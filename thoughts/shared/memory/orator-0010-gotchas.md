Building **0010 orator** — lifting faerrin `lark` (single-process Bun Discord music bot) into
**orator-backend** + merging `birdfeed`→**orator-controller**. Scope+spec at `thoughts/{shared/research/
2026-06-20-orator-0010-thoughts.md, astra/specs/0010-orator-spec.md}`. Decisions **M1–M5** locked (see spec);
the big one is **M3 = one process serving a TanStack *Router* client SPA (NOT react-start/SSR)** — forced
because the backend must keep a hand-rolled `Bun.serve` REST API for the Stream Deck controller, and pinned
react-start 1.168 has no file server routes (see [[tanstack-start-skill]]).

**Substrate was pre-staged (headline):** `config.kdl` already had `orator`/`orator-controller` blocks +
`@astra/config` parsed them 1:1 with lark's env, and SOPS already carried `orator_*` keys. Only addition:
`orator.database-url`. **GOTCHA — config is single-source across BOTH toolchains** ([[config-single-source]]):
`config.kdl` is parsed by the TS Zod schema *and* the **strict** Python `OratorConfig`
(`libs/py/config/.../models.py`). Adding the KDL key + only the TS field passed every bun lane but failed
`uv run pytest` collection with `extra_forbidden` on `orator.database_url` for **every** config-loading test
(the whole linguist suite) — a cross-toolchain CI failure invisible to app-scoped local checks. Always mirror
a new KDL field in **KDL + Zod + the Python pydantic model**, and reproduce the **full** CI lanes
(`uv run pytest`, `bunx biome ci .`, `bun --filter '*' …`), not just the app you touched.

**Load-bearing gotchas (slices 1–6):**
- **sync `bun:sqlite` → async Bun `SQL` (Postgres) is the whole port's spine (Decision F).** lark's `repo.ts`
  was synchronous; astra's `LibraryStore`/`PostgresStore` (`db/store.ts`) is async, which ripples `await`
  through every route/playback/ingest call. PostgresStore uses `.unsafe(query, $n params)` (keeps the port
  1:1 with lark's `(sql, params)` shape), `RETURNING` for inserts, `RETURNING id`→`rows.length>0` for
  changed-checks, `on conflict do nothing` for `INSERT OR IGNORE`, `lower()` for `COLLATE NOCASE`,
  `sql.begin` for transactions, and `::text` casts on timestamps so row shapes stay strings.
- **No live Postgres in CI (weal-bot precedent).** The PostgresStore wire layer is exercised at slice-6
  integration + deploy, NOT in CI. Tests use `db/fake-store.ts` — an **in-memory `LibraryStore` double**
  (collections/tracks/jobs/items/api-keys real; tags/playlists `notImpl()`); the playback engine takes a
  **narrow `PlaybackStore`** (getTrack + markTrackError) so its test fake is 2 methods.
- **Schema IDs are `generated by default as identity`** (not `always`) so the slice-6 migrator can insert
  explicit ids to preserve the load-bearing collection/track FKs; the migrator resets each sequence after.
- **Voice/DAVE (L3 verified real):** `@discordjs/voice` + the **native `@snazzah/davey`** (an
  `optionalDependency`) — must build in the Docker image (slice 9) or the WS closes 4017. `discord-voice.ts`
  lifted ~verbatim; opusscript stays a dep but ffmpeg pre-encodes it out of the realtime hot path. `index.ts`
  forces `dns ipv4first`. The **bot is optional**: no resolved `discordToken` ⇒ playback routes 503, web+library
  still run (the deferred live-Discord seam).
- **Auth lift:** OAuth2 `identify` is **login-only** → a stateless signed cookie (`sessions.ts`); preserve the
  **stateless HMAC `state`** (CSRF, no cookie round-trip), the **"Add to Server" callback branch**, and
  `Bun.serve({idleTimeout:60})` (voice-join latency). **Rebrands:** cookie `lark_session`→`orator_session`,
  header `x-lark-key`→`x-orator-key`, raw-key prefix `lark_`→`orator_` (hash is of the raw key, so migrated
  keys keep verifying). Key **minting is session-gated** — the Stream-Deck controller can't mint, only consume.
- **M1 allowlist** = ontology `is_admin` players' snowflakes ∪ optional `orator.allowedUserIds` override
  (`src/allowlist.ts`), fed into `config.allowlist: Set<string>`.
- **`ingest.start()` is now async** (the job row is created on Postgres) — lark returned it synchronously; the
  REST handler `await`s `start()` then `void done`s the background downloads.
- **Ports:** orator-backend **10363**, orator-postgres **10364** (Compose unit added, mirrors weal-postgres).
- **astra biome is stricter than faerrin's** — lifted lark code tripped `noNonNullAssertion`,
  `noAssignInExpressions`, `noUnusedFunctionParameters`, and organizeImports; fix on lift, don't fight it.
