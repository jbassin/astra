### 2.2 Pipeline mechanics (apps/codex)

- Stages (`scripts/transform.ts`, run by `just codex-refresh`): fetch:foundry → fetch:aon →
  transform (loadFoundrySide → loadAonSide → join → **drop** → crossref-dedupe → level-default →
  bookNormalize → sidebarAttach → augmentClassStats → emit → rules-tree/sources-index → report) →
  search index (host-only) → assay-export copy → container restart. `runTransform` is a pure
  function of `TransformPaths` (fixture double-run byte-diff is the determinism gate).
- **Foundry-only spells are DROPPED today**: an unjoined Foundry draft survives `runJoin` but
  `applyAonPrimaryDrop` (`src/ingest/drop.ts:213-218`) keeps only AoN-backed docs, 1:N variants,
  and the `creature`/`hazard` carve-out (`CARVE_OUT_CATEGORIES`, drop.ts:73). **No dormant
  Foundry-only-spell path exists** — the bypass is new code in `drop.ts`.
- **licenseMap.ts needs NO change**: it's consulted only for AoN-only/journal docs. Foundry-derived
  docs resolve license/edition from their own `system.publication`
  (`deriveSourceAndEdition`, `src/ingest/foundryEntities.ts:323-341`); the store's `OGL` +
  `remaster:true` yield `license:"OGL"`, `edition:"remaster"` cleanly. (`unknown` license is
  report-counted residue, never a hard fail — but we don't hit it.)
- **`ritual/` is unreachable for Foundry-only docs**: `mapCategory` keys on (pack, doc-type) only;
  category `ritual` is assigned solely at join time via an AoN match (`isRitualMove`,
  `join.ts:263-265`). The 3 homebrew rituals need explicit category routing. → **R2**.
- **Pack discovery is manifest-driven** (`system.pf2e.json` packs[] → `buildPackRegistry` +
  `assertRegistryIsTotal`): the store can't ride it. New seam = a `homebrewPath` on
  `TransformPaths` + a parallel walk, reading the committed store **directly from the repo path**
  (it's versioned content, stronger provenance than a snapshot copy; add a corpus-manifest pin —
  count + dir hash — for report visibility).
- Emit gate: `CORPUS_SCHEMA_VERSION = 5`; `CodexEntitySchema.parse` (`.strict()`) hard-fails the
  run. Required: id/slug/category/name/edition/source{book,license}/traits/body/facets — all
  derivable from the store docs via the existing `assembleFoundryEntity`. `superseded` derives
  from `remasteredAs` (absent → visible by default). No `aonUrl` → the AoN link row simply omits.
- `@UUID` conditionitems refs resolve at ingest against the full corpus id set; a miss downgrades
  to `brokenRef` (plain span, no dead link) — official condition targets exist, so the 70
  ref-bearing docs resolve normally.

### 2.3 Surfacing seams

- **Source filter/listing**: options derive live from `row.source.book` — LotI2 appears in the
  Source facet and columns automatically. Product-line grouping comes from `sources-index.json`,
  whose `productLine` is majority-voted from AoN citations only → a homebrew book lands in
  **"Other"** among ~253 Foundry-only books; there is **no manual productLine override mechanism**
  today. → **R3**.
- **Abbreviations**: `abbreviateBook()` returns `undefined` for unknown books → all 7+ call sites
  fall back to the full title (no crash). "LotI2" verified collision-free vs the 243 curated codes
  (nearest: LOIL2/LOTG — distinct). Add one `OTHER_OVERRIDES`/curated entry.
- **Traits**: no allowlist — any trait renders (`CodexTraitPill`), humanized, umber default bucket.
  School traits are filterable via the tri-state traits facet out of the box. A trait pill links to
  `/trait/<slug>` only if a `trait/` doc exists; the 8 school traits would render as **plain
  unlinked pills**. → **R4**.
- **Spell facets**: traditions/castTime/range (+ core level/rarity/source/edition/traits). No
  school facet exists (traits facet covers it).
- **Search**: `build-search.ts` indexes every corpus row unconditionally — homebrew rides the next
  reindex; `book` is display-meta only (no source filter dimension in search — pre-existing).
- **Edition**: `remaster:true` → the Four-Point Spark icon, same as official remaster content
  (accepted — the store is Remaster-idiom by construction).
- **Detail page**: citation renders the full book title; no AoN link; embeds/crossrefs fail soft.
- **Nav**: `/spell` (and `/ritual`) listings are unified over all sources — zero nav changes.
- **Assay block**: still hidden (`emptyAssayReader`, `corpusFns.ts:33-41`) — orthogonal; even if
  revived, `spell-power.json` covers official ids only (homebrew ids fail soft to no-block).
  Not touched by this work.

## 3. Proposed mechanism (for the spec)

1. **Loader**: `loadHomebrewSide` walking `apps/assay/homebrew/spells/*.json` (path threaded via
   `TransformPaths.homebrewPath`), assembling entities through the existing
   `assembleFoundryEntity` — no parallel assembly logic.
2. **Provenance flag**: mark these entities (e.g. `sourceKind:"homebrew"` internal to the
   transform) so `applyAonPrimaryDrop` exempts them explicitly (a keep-predicate arm, not a
   category carve-out — homebrew must not accidentally keep official Foundry-only spells).
3. **Category**: `spell/` for 172; the 3 `system.ritual` docs route to `ritual/` (R2), keyed on
   `system.ritual` presence (the only reliable marker — NOT cast time, §2.1).
4. **Ids**: plain `spell/<slug>` / `ritual/<slug>`; the store is collision-free post-R1 (no
   join-time identity machinery — homebrew never pairs with AoN/legacy docs). The spec should
   still add a hard ingest-time guard: a homebrew id colliding with an existing corpus id is a
   transform error, not a silent overwrite (future store additions will re-hit this class).
5. **Manifest/report**: corpus-manifest gains a `homebrew` pin (count + dir hash); report.md gains
   a homebrew section (count in/emitted, ref resolution stats).
6. **Surfacing deltas**: one `abbreviateBook` entry ("Liturgy of the Iridite Vol.2" → "LotI2",
   verified collision-free vs the 243 curated codes); a small pinned-product-line override so
   LotI2 groups under a new **"Homebrew"** group, listed last (R3 — new seam in
   `sourcesModel.ts`; none exists today, keep it a tiny book→group map, reuse-don't-redeclare
   the pinned-order machinery); **8 `trait/` docs for the school traits** (R4 — see §3a).
7. **Deploy**: standard codex staged order (image → transform → reindex → codex-scoped up);
   expected counts spell 2,461→2,633 · ritual 201→204 · trait +8 (**expectations, not pins** —
   confirm by running the real transform before speccing numbers, per the proxy-pin lessons).
