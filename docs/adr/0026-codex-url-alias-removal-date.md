# 0026. codex's "forever" URL aliases get a removal date

- **Date:** 2026-10-22
- **Status:** Accepted, not yet built
- **Source:** [2026-10-22-techdebt-paydown-0037-thoughts.md](../../thoughts/shared/research/2026-10-22-techdebt-paydown-0037-thoughts.md) (section 0, decision table)

## Context

codex keeps old URL forms (for example `?legacy=`) working forever on a site that is noindexed.

## Decision

Set a removal date and delete the aliases after it.

## Consequences

Old shared links stop working after the date.
