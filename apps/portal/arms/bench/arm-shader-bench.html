Arm

The hand is drawn by Buffer A in "the map around the shoulder" mode (the free-smears starter). Hand size is in token radii (1 = a 2 × 2 token); the thumb follows the bend direction.

Smear room widens the drawn strip past the arm, in multiples of the arm's width on each side, so smears can drift out. Smooth curve bends the strip smoothly through the joints; off, it is straight segments with sharp corners, like the module draws now.

Widths are in grid squares (140 px), like the flag's shoulderWidth and wristWidth. Each segment is 500 px.

Inputs your shaders get (declared for you)

Both passes

uTime
Seconds since the page loaded.
uLength
Whole arm length in pixels.
uSegments
Number of segments.
uArmSize
Strip length and average strip width in pixels (the width includes smear room). uArmSize.x / uArmSize.y is the strip's aspect ratio, the stand-in for Shadertoy's iResolution.x / iResolution.y.
uBody
How much of the strip's width is the arm itself: 1 with no smear room, 0.5 with room 0.5 (half the strip is arm, a quarter of margin on each side).
uBuffer
Buffer A's texture. In Buffer A it is last frame; in the image pass it is this frame.
uBufferSize
Buffer A's size in texels (1024 × 128).
uColorA/B/C
The three colours above, as vec3.
PI
Defined as 3.14159265.

Image pass (drawn on the arm)

vUv.x
0 at the shoulder, 1 at the hand.
vUv.y
−1 on one edge, +1 on the other, 0 on the centre line.
vDist
Pixels from the shoulder along the arm.
vSeg
Segment index plus the fraction along it: 1.25 is a quarter of the way down the second segment.
vHalf
Half the arm's width here, in pixels. (1.0 - abs(vUv.y)) * vHalf is pixels in from the edge.
bufferUv()
Where this point of the arm is in Buffer A. Read it with texture2D(uBuffer, bufferUv()).

Buffer A (the arm unrolled into a 1024 × 128 strip)

vUv
0 to 1 across the strip: x from shoulder to hand, y from one edge to the other. Same as Shadertoy's fragCoord / iResolution.
uDelta
Seconds since the last frame, like iTimeDelta.
uFrame
Frame count since the buffer was cleared, like iFrame.
motionAt(x)
How far the arm moved this frame at vUv.x = x, in strip UV units. Sampling last frame at vUv + motionAt(vUv.x) leaves ink behind in the world as the arm moves.

"The map around the shoulder" mode

Buffer A is a 1024 × 1024 square fixed to the map, centred on the shoulder and big enough for anywhere the arm can reach. The image pass is drawn over that whole square, not just the arm, so smears show wherever they drift. In both passes:

vUv
0 to 1 across the square.
uArm
Where the arm is this frame. .r is 1 on its centre line, falling to 0 at its edge and off it; .g is how far along it (0 shoulder, 1 hand); .b is across it (0 one edge, 1 the other).
uRegion
The square: .xy its top-left corner on the map, .z its size in pixels, .w its size in texels.
uHand
Buffer A only. .xy the hand point (token centre) on the map, .zw the arm's direction there.
uHandR, uHandSide, uHandOn, uCurl
Buffer A only. Hand size in pixels, thumb side (±1), 1 when the hand is on, finger curl 0 to 1.

Write gl_FragColor. On the arm, use premultiplied alpha: vec4(colour * a, a). Buffer A stores 8 bits per channel, so very slow fades can stall.
