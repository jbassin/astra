# 0013. Short decisions use the question tool; decisions with context use plain text

- **Date:** 2026-10-22
- **Status:** Accepted
- **Source:** [2026-10-22-techdebt-paydown-0037-thoughts.md](../../thoughts/shared/research/2026-10-22-techdebt-paydown-0037-thoughts.md) (section 0, decision table)

## Context

The question tool hides the context written before it, which made long decision cards unreadable.

## Decision

Use the question tool for short choices. When a choice needs context, ask in plain text. Ask only for product, cost and stakeholder calls; decide the rest and say what was decided.

## Consequences

Questions the repo can answer are answered by checking, not asked.
