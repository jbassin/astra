# Action-glyph asset provenance

**Legal posture:** stakeholder-cleared on the record ("I've checked with our lawyers and we have
permission" — 0029 P6 scope doc, R5). This file records only the technical provenance.

`src/domain/render/actionGlyph.tsx` renders action costs with the Paizo "Pathfinder-Icons" font at
`apps/codex/web/public/pathfinder-icons.ttf`: a `<span>` carrying one Private-Use-Area character,
styled through a self-hosted `@font-face` in `globals.css`.

## Source

- **File:** `apps/codex/web/public/pathfinder-icons.ttf`.
- **Font metadata (from its own `name` table):** family `Pathfinder-Icons`, "Version 2.0", "Font

- **unitsPerEm:** 1024; ascent 960 / descent −64 (`head`/`hhea`/`OS/2` tables agree).

## Codepoint to cost mapping (verified with `fontTools`)

The font ships a `GSUB` ligature table (`liga` feature, `latn` script) that maps bracketed names to
Private-Use-Area glyphs:

| Ligature string      | Resolves to | `ActionCost` |
| -------------------- | ----------- | ------------ |
| `[one-action]`       | `U+E902`    | `"1"`        |
| `[two-actions]`      | `U+E901`    | `"2"`        |
| `[three-actions]`    | `U+E900`    | `"3"`        |
| `[reaction]`         | `U+E904`    | `"reaction"` |
| `[free-action]`      | `U+E903`    | `"free"`     |
| `[uniE905][uniE905]` | `U+E904`    | unused (`uniE905` is an empty glyph) |

`GLYPH_CHARS` uses the raw codepoints rather than `liga` substitution of the bracketed strings, so the
glyph survives `renderToStaticMarkup` and plain-text extraction, neither of which shapes fonts.

Extraction method: `fontTools.ttLib.TTFont(...)['GSUB'].table.LookupList.Lookup[0].SubTable[0].ligatures`
(a `LigatureSubst`, `LookupType == 4`, keyed by first-glyph name).

## Pre-composed multi-action glyphs

The font ships two- and three-action costs as their own wider glyphs. Advance widths: one-action, free
and reaction ≈ 1024 units (1em); two-actions ≈ 1600 (1.56em); three-actions ≈ 2128 (2.08em). Normal text
layout sizes them correctly with no manual composition.

`EditionIcon.tsx` (the Remaster/Legacy pills) is separate: it stays inline SVG through `GlyphDefs.tsx`.
