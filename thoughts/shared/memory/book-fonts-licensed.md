Josh holds the licence for every font in `apps/assay/py/books/liturgy_vol2/assets/fonts/` and has
permission to distribute the book PDF with them embedded. Don't raise font licensing as a risk,
a backlog item, a distribution caveat or a public-repo concern.

**Why:** Josh has said this several times and was still being asked about it, because older notes
described the fonts as personal-use only.

**How to apply:** If a doc or note calls these fonts personal-use or asks for a licence check,
correct that text in place instead of repeating the warning.
