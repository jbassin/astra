# docs

The living docs. Each describes the current state; history lives in git and in
[`thoughts/archive/`](../thoughts/archive/).

- [`now.md`](now.md) — what is in flight, what is blocked, and the next action. Read first.
- [`backlog.md`](backlog.md) — every open item with an owner, including stakeholder gates.
- [`architecture.md`](architecture.md) — what runs where: pipeline, services, edge, deploy checkout, data root, astra-data.
- [`development.md`](development.md) — setup, the `just` commands, toolchains, conventions, adding an app, traps.
- [`runbook.md`](runbook.md) — recovery procedures with the exact commands.
- [`adr/`](adr/README.md) — binding decisions and accepted security risks, one per file.
